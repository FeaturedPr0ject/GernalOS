# Backup handling

Do not commit full firmware images, raw partition dumps, private device data, or personal backups to this repository.

Keep backups locally in a secure location. Store only non-sensitive metadata here, such as:

- image filename and partition name
- source firmware/build identifier
- file size
- SHA-256 checksum
- extraction tool and version
- date and verification notes

Before sharing any binary, verify its license and redistribution permission. Never include userdata or personal information.
