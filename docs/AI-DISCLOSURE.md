# AI Assistance Disclosure

## Important notice

**GernalOS is an AI-assisted project.** Some repository documentation, explanations, planning material, and technical edits have been produced with help from AI tools.

This does not mean that every line of code or every technical decision was independently written or verified by a human. AI-generated material can contain errors, omissions, outdated instructions, or unsafe assumptions.

## Verification requirements

- Verify device properties and partition details against the actual Alcatel 9032X firmware and hardware.
- Review every command before running it, especially commands that write, erase, unlock, or flash partitions.
- Do not treat generated device-tree data, kernel configuration, build instructions, or image metadata as proof that a build is bootable.
- Test experimental changes only with a complete backup and a device-specific recovery plan.
- Clearly label measured facts, hypotheses, and unverified AI suggestions.

## Project status

The repository is currently a research and bring-up workspace. No GernalOS/ApolloOS build is claimed to be bootable or safe to install.

## Scope of this disclosure

This notice describes the use of AI assistance in project materials. It is not a claim that the entire repository, all future code, or the underlying stock firmware was generated by AI.
